# @page-agent/connect

Commercial on-ramp for [PageAgent](https://github.com/alibaba/page-agent): log in providers, pick models, and export a one-line connect snippet.

```bash
# from repo root
npm start
```

See the root [README](../../README.md) for product overview, integration patterns, and production auth guidance.
